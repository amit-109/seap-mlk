# seap-mlk

SEAP orientation portal for MLKPG College, Balrampur.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Registration, learning and assessment take place on the official SEAP portal: https://spokenenglish.wadhwaniai.org/

Video tutorial URLs are maintained in `src/data/videos.js` and remain placeholders until verified links are supplied.
